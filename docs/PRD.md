# SIDE — 短窗口交易判断

## 用户与问题

主动 SOL 交易者需要在几秒到几分钟内判断方向和等待时机。同一资产的现货与永续交易分散在中心化交易所和 DeFi 场所，单一价格图难以说明市场是否一致、哪类资金在推动，以及证据是否仍然新鲜。

## 产品任务

将四类市场证据汇总成可解释的短窗口判断：CEX 现货、CEX 永续、Solana DEX 现货流和 DeFi 永续。初始窗口为 5 分钟。

- `BUY BIAS` / `SELL BIAS`：价格变化和主动买卖流支持同向偏向。
- `NO EDGE`：证据不足以形成方向共识，等待也是有效输出。
- `INSUFFICIENT DATA`：新鲜数据不足，停止输出有效方向。

界面展示来源、新鲜度、覆盖范围与分歧，帮助用户理解判断依据。

## 使用流程

1. 观察实时跨市场证据及方向偏向。
2. 检查市场一致性、数据质量和执行估算。
3. 记录模拟决策，或运行配置固定的自动 dry-run 策略。
4. 保存行情与决策，使用确定性回放和历史回测验证结果。

0x / Jupiter 只提供执行估算；报价不被当成已发生成交或方向信号。v0.4/v0.5 不签名、不广播、不使用真实资金。

## 成功标准

- 用户能快速识别方向、分歧及数据不可用状态。
- 相同数据和模型版本产生相同判断。
- 过期报价、断流和损坏数据有明确失败状态。
- 模拟决策可追溯至当时的数据和参数。
- 策略价值通过足够样本、样本外测试与费用分析检验，不能由训练期盈利推断。

## 范围

当前围绕 SOL 和短窗口决策展开，不承诺盈利，不声称覆盖整个 Solana 市场。实际部署保持私有访问，详见 [安全说明](../SECURITY.md)。
